Ebenen

Klick auf eine Ebene macht sie aktiv. Neue Noten gehören zur aktiven Ebene. Gesperrte Ebenen bleiben unverändert. Stumme Ebenen werden nicht abgespielt.

Instrumente

Bedienung

Klick setzt oder entfernt eine Note. Ziehen malt mehrere Noten.
Auswahl: Rechteck ziehen, markierte Noten verschieben.
Klick auf die Tastenleiste spielt eine Vorschau.
Klick auf die Zeitleiste setzt den Abspielkopf.

Mausrad: vertikal
Shift + Rad: horizontal
Strg + Rad: Zoom
